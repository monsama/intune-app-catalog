            Getting started: catalog and Intune
            
              The catalog is a folder of one JSON file per app. Pick where you start:
              
            
              
              
              
                ⇩
              Intune has apps, the catalog is empty
              
                
              Checks lists every app in Intune that isn't in the catalog - tick them and Add to catalog. Their settings and groups come along.
              
                
              
              
              
              
                ⇧
              The catalog has apps, Intune doesn't
              
                
              Add app (Find... looks up the Winget ID), set the groups, then Send to Intune - several at once, in dependency order. Apps with their own installer need More > Package and a detection rule first.
              
                
              
              
              
              
                ⇄
              Keeping them in step
              
                
              Checks finds every difference - renamed apps, settings, groups, dependencies, unknown assignments, Winget IDs - each with its fix: Pull if Intune is right, Push if the catalog is.

                    Managed updates
                    
          
                    Apps with managed updates install a fixed version. A new version is released to these groups first (Required), and to everyone when it's promoted. Groups that Entra ID doesn't have yet are created when used.
                    
          
          
                    Release rings after the pilot groups (optional): a release that passes the rule in one ring goes on to the next, then to everyone. Add a ring, name it and give it its groups.
